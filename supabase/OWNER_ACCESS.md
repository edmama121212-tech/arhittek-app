# Доступ по должности

- Владелец — одна существующая подтверждённая учётная запись Мансура, зафиксированная в закрытой таблице. Изменение имени, должности и старого is_admin другого сотрудника не передаёт владение.
- Владелец видит все проекты, финансы, табель и все инструменты.
- Ведущий архитектор и ведущий дизайнер видят свои проекты и только КП/Договор в «Ещё».
- Остальные видят свои проекты без «Ещё».
- Должности выбираются из списка. Старые названия сохраняются до явного изменения; неизвестное название не получает права ведущего.
- До ответа get_employee_access защищённые экраны скрыты. Отсутствующий RPC, ошибка и неверная/истёкшая сессия закрывают доступ.
- Финансовые регистры, табель и оклады не запрашиваются для сотрудников и закрыты отдельными серверными правилами.

Установка: применить session-security.sql и owner-access.sql одной транзакцией после проверок. Не публиковать клиентскую версию, требующую новый get_employee_access, без успешно установленного сервера. Пользовательские деньги и история не изменяются.

Проверки: npm run test:security. Дополнительно CI проверяет существующие финансовые и браузерные сценарии.
