# Матрица элементов управления ARHITTEK, 19 ноября 2026

Повторный проход в Chromium 157.0.8103.78 дал **4 509 измерений в 240 состояниях**. Матрица содержит 451 комбинацию «роль, состояние экрана, элемент», из них 450 наблюдались во всех 10 профилях. Заголовок платёжного календаря с программным фокусом наблюдался в девяти профилях. Одна и та же кнопка, показанная разным ролям или на разных экранах, учитывается в нескольких строках. Покрыты 24 состояния ролевых маршрутов, 18 названий экранов и четыре роли. Набор включает переработанный финансовый раздел, платёжный календарь и форму расхода. Данные синтетические.

Для каждого видимого элемента проверялись прокрутка до элемента, попадание в центр через hit test, перенос фокуса при доступности через tabIndex, возможность определить подпись, размер и горизонтальная обрезка. В модальном окне область проверки ограничивалась диалогом. Механизм находит нативные контролы, распространённые ARIA-роли, явные обработчики onclick, элементы с tabindex и связанные подписи. Предусмотренное скрытие элементов по правам не считалось дефектом.

| Метка | Как читать ячейку |
|---|---|
| OK | Перечисленные технические проверки не выявили отклонений. |
| K | Фокус через последовательную навигацию и вызов focus не подтверждён. |
| N | Не обнаружена подпись по проверяемым DOM-атрибутам, связанным label или тексту. |
| T | Минимум одна сторона прямоугольника меньше 24 CSS px. Для label нужно дополнительно учитывать связанное поле и расстояние до соседних целей. |
| C | scrollWidth больше clientWidth внутри элемента с overflow-x:hidden. Возможна намеренная обрезка. |
| H / V | Центр перекрыт либо элемент остался вне экрана после прокрутки. |
| D / — | Действие отключено / элемент не наблюдался. |

Количество строк изменилось с 440 до 451. Новый финансовый интерфейс и дополнительные связанные подписи изменили состав матрицы. Числа по признакам относятся к видимым элементам соответствующей версии.

Во всех десяти профилях зафиксированы 24 комбинации «роль, исходный экран, действие, следующий контрольный экран» — всего 240 реальных нажатий. Медиана времени от начала click до второго requestAnimationFrame составила **30 мс**, p95 **48 мс**, максимум **62 мс**. Ошибок прохождения маршрутов и необработанных исключений страницы нет. Это время реакции браузера на тестовом компьютере. Серверное подтверждение платежей и реальные сетевые задержки измеряются отдельно. Значения времени в матрице относятся к самой DOM-диагностике.

Отдельный сквозной тест клавиатуры проверил открытие карточки проекта пробелом, переходы по вкладкам стрелкой, Home и End, выбор фильтра этажности с изменением aria-pressed, открытие строительного объекта Enter, вкладку закупки и вызов системного диалога выбора фотографии с клавиатуры. Дополнительный проход сохранил 96 снимков на ширинах 320, 390, 768 и 1440 px. Все состояния открылись без ошибок страницы и переполнения документа по горизонтали. На узком экране 320 px визуально просмотрены раздел «Операции и планы», платёжный календарь и форма записи расхода. Оценка удобства людьми, экранными дикторами и на физических телефонах остаётся вне этого измерения.

## Граница покрытия

Матрица подтверждает десять различных условий отображения каждой строки и отдельно перечисленные нажатия. Десять независимых бизнес-сюжетов для каждой кнопки, включая ошибку записи, повтор после тайм-аута, конкурирующее редактирование, отсутствие прав и отмену, этим набором не подтверждены. Данные имитируют серверные ответы. Отдельный серверный и интеграционный регресс должен подтверждать изменение данных, проводки, документы и доставку внешнего уведомления.

Воспроизведение с установленными зависимостями и Chromium: установить переменные окружения AUDIT_CONTROLS=1, BROWSER_EXECUTABLE и AUDIT_SCREENSHOT_DIR, запустить node tests/visual-audit.cjs. Исходные результаты с метриками по каждому наблюдению записываются в controls.json. Для сквозной проверки клавиатуры запустить node tests/keyboard-workflow.cjs. Замеры получены на изолированной копии приложения с исправлениями, включая новый финансовый раздел. Перед запуском сверены SHA-256 семи файлов приложения и тестов.
