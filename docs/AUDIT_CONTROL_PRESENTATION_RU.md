# Матрица элементов управления ARHITTEK, 19 ноября 2026

В Chromium 157.0.8103.78 выполнено **4 400 измерений**. Каждая из 440 комбинаций «роль, состояние экрана, элемент» присутствовала во всех десяти профилях. Всего открыто 240 состояний экранов. Одна и та же кнопка в нескольких ролях или состояниях учитывается несколько раз. Это выборка по 24 маршрутам и состояниям рабочего приложения, охватывающая 18 названий экранов и четыре роли. Сценарии работают на изолированных синтетических данных.

| Файл | Содержимое |
|---|---|
| [Матрица по элементам](AUDIT_CONTROL_PRESENTATION.csv) | Каждая строка содержит роль, экран, идентификатор/текст элемента, число профилей, время диагностической проверки, минимальные размеры и десять фактических результатов. |
| [Журнал нажатий](AUDIT_CONTROL_CLICKS.csv) | В каждой строке одно штатное нажатие Playwright, название действия, раздел до нажатия, следующий снимок, активный раздел после двух кадров и время в миллисекундах. |

Для каждого видимого элемента проверялись прокрутка до элемента, попадание в центр через hit test, перенос фокуса при доступности через tabIndex, возможность определить подпись, размер и горизонтальная обрезка. В модальном окне область проверки ограничивалась диалогом. Механизм находит нативные контролы, распространённые ARIA-роли, явные обработчики onclick, элементы с tabindex и связанные подписи. Предусмотренное скрытие элементов по правам не считалось дефектом.

| Метка | Как читать ячейку |
|---|---|
| OK | Перечисленные технические проверки не выявили отклонений. |
| K | Фокус через последовательную навигацию и вызов focus не подтверждён. |
| N | Не обнаружена подпись по проверяемым DOM-атрибутам, связанным label или тексту. |
| T | Минимум одна сторона прямоугольника меньше 24 CSS px. Для label нужно дополнительно учитывать связанное поле и расстояние до соседних целей. |
| C | scrollWidth больше clientWidth внутри элемента с overflow-x:hidden. Возможна намеренная обрезка. |
| H / V | Центр перекрыт либо элемент остался вне экрана после прокрутки. |
| D / — | Действие отключено / элемент не наблюдался. |

## Фактические результаты

- В журнале 240 реальных нажатий. Каждая из 24 комбинаций «роль, исходный экран, кнопка, следующий контрольный экран» пройдена во всех десяти средах. Ошибок выполнения маршрутов и необработанных исключений страницы не зарегистрировано.
- От начала события click до второго requestAnimationFrame медиана составила **30 мс**, p95 **49 мс**, максимум **63 мс**. Значения характеризуют реакцию локального интерфейса на этом компьютере. Время подтверждения операции сервером и реальные сетевые задержки требуют отдельных измерений. Время в матрице измеряет саму DOM-диагностику, включая прокрутку, поиск цели и перенос фокуса.
- Сигнал K получили 65 строк матрицы в 650 измерениях. Среди них кликабельные показатели и табличные строки рабочего стола. Это приоритет для проверки клавиатурного пути.
- В пяти строках обнаружены поля без распознанной подписи, среди них сумма и дата выплаты, дата накладной у администратора и прораба. Всего 50 наблюдений.
- Сигнал T получили 101 строка в 866 измерениях, C — три строки в 18 измерениях. Обрезка зафиксирована у индикатора пользователя дизайнера. Ни в одном измерении не зафиксировано перекрытие центра или невозможность прокрутить цель в область просмотра.
- Удобство оценивалось по измеримым признакам. Тестирование людьми, экранными дикторами, реальными мобильными устройствами и оценка эстетики каждого состояния остаются отдельными этапами.

## Граница покрытия

Матрица подтверждает десять различных условий отображения каждой строки и отдельно перечисленные нажатия. Десять независимых бизнес-сюжетов для каждой кнопки, включая ошибку записи, повтор после тайм-аута, конкурирующее редактирование, отсутствие прав и отмену, этим набором не подтверждены. Данные имитируют серверные ответы. Отдельный серверный и интеграционный регресс должен подтверждать изменение данных, проводки, документы и доставку внешнего уведомления.

Воспроизведение с установленными зависимостями и Chromium: установить переменные окружения AUDIT_CONTROLS=1, BROWSER_EXECUTABLE и AUDIT_SCREENSHOT_DIR, запустить node tests/visual-audit.cjs. Исходные результаты с метриками по каждому наблюдению записываются в controls.json. Замеры сделаны в копии исходного коммита c85be96 с исправленным маршрутом финансового аудита и переносом кнопок на узких экранах.
