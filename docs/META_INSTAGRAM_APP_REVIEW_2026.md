# ARHITTEK Catalog — Meta App Review: пакет подготовки

Дата: 2026-11-23. Meta App ID: `1192662563090694`; Instagram: `@arhittek.plans`; Unified Login config: `1703509418068198`.

## Назначение

ARHITTEK управляет каталогом готовых проектов частных домов. Клиент оставляет комментарий с запросом «проект» под публикацией `@arhittek.plans`. Приложение обрабатывает событие комментария через официальный Instagram webhook, выдаёт одноразовую персональную ссылку на клиентский каталог (срок 48 часов) и отправляет **один private reply** в Instagram Direct. Форма обращения в WhatsApp доступна из каталога. Клиентам недоступно скачивание PDF-альбома.

## Минимальные разрешения (Unified Login)

- `instagram_basic`: идентифицировать подключённый профессиональный аккаунт и проверить, что события относятся к `@arhittek.plans`.
- `instagram_manage_comments`: получать события `comments` с текстом и идентификатором комментария; обрабатывать только запросы о проектах.
- `instagram_manage_messages`: отправлять private reply с индивидуальной ссылкой по `comment_id`.

**Не запрашивать:** `ads_management`, `ads_read`, `instagram_content_publish`, доступ к рекламным аккаунтам, публикацию от имени клиента или полный партнёрский контроль.

## Проверенная техническая схема

1. Meta App webhook `comments` -> `https://chbkkoxwzpaghanofvqk.supabase.co/functions/v1/instagram-catalog`.
2. GET challenge — проверка `META_VERIFY_TOKEN`, HMAC SHA-256 для POST по `META_APP_SECRET`. Secrets доступны только в Supabase Edge Function Secrets.
3. Определение ключевых слов запроса, исключение собственного комментария, проверка допустимости времени события.
4. Атомарное создание записи отправки; защита от дублей.
5. Персональная ссылка с `expires_at = created_at + 48h`.
6. Отправка Instagram private reply: `recipient.comment_id`; журнал `message_id` при успешном ответе Meta.
7. Клиентский каталог использует `get_public_catalog(token)`; сервер отвергает истёкшие/удалённые ссылки. Прямое анонимное чтение таблиц закрыто.

**Состояние на момент подготовки:** Meta callback был подтверждён, переключатель `comments` в App Dashboard — On. Реальных доставленных Direct — 0; тестовый комментарий не появился в журнале Supabase. Работа со всеми обычными клиентами НЕ подтверждена.
