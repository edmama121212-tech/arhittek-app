# Доступ к прежним формам доходов и расходов

Проверен сеанс владельца в мобильном Chromium на изолированном активном снимке финансов версии 2 с режимом начала учёта с нуля. Сборка index.html / finance-workspace.js — `aea6aa0772fa/d42c9a9a480b`. Формы `companyExpenseSheetOverlay` и `companyIncomeSheetOverlay` присутствуют в общей разметке.

| Открытый путь | Фактический результат |
|---|---|
| Финансы → Записать поступление | Открывается форма в `financeWorkspaceModal`. |
| Финансы → Ещё → История операций, Архив до начала учёта, Платёжный календарь, Прогноз по проектам, Сейф, Регулярные платежи | Проверены все шесть переходов. На открытых страницах прежние кнопки добавления дохода, расхода и оплаты офиса скрыты. |
| Проекты → Учебная мастерская → Деньги | Для расхода в самой карточке видна кнопка `pf-expense-add-btn`. Отдельно показан итог прямых расходов. |
| Там же → Принять платёж | Открывается `paymentSheetOverlay`. |

UI-0165, UI-0167, UI-0168, UI-0171, UI-0173, UI-0175, UI-0176 и UI-0179 не получили зачёта по этому запуску. Сохранённые в коде вызовы из прежних финансовых экранов относятся к отдельному маршруту совместимости. Тест покрывает перечисленные переходы активной версии 2. Проверить можно командой `node tests/project-direct-cost-ui.cjs --routes`.

Для действующего поля UI-0215 проверены сумма прямых затрат договора, сводка и расход за выбранный финансовой системой месяц. [13 сценариев и замеры](QA_DIRECT_COST_RUNS.csv)
