# Независимая синхронизация Instagram → Google Sheets

Работает **без ChatGPT Automations** после единственного подключения владельцем Google-таблицы. Google Apps Script запускает `syncInstagramRecipients` каждые 5 минут через собственный time-driven trigger Google.

### Защита

1. Скрипт привязан только к личной Google-таблице [ARHITTEK — Получатели каталога Instagram](https://docs.google.com/spreadsheets/d/1ZtoRdi5O9coUHX2sR9zh4WsdBOC8exY6qUIsbEW9c-o/edit).
2. Google Apps Script получает краткоживущий OpenID Connect ID-токен `ScriptApp.getIdentityToken()`.
3. Supabase Edge Function `instagram-recipients-export` проверяет подпись токена по публичным Google JWKS, issuer, срок жизни, audience Google OAuth и конкретного владельца Google по хешу `sub`. **Никакого постоянного общего ключа нет.**
4. Затем Edge Function от имени сервера делает доступный только `service_role` запрос `instagram_sheet_confirmed_rows()`, который возвращает только реально подтверждённые отправки `state='sent'` с `message_id`. Не возвращает токены каталога, Meta Access Token, App Secret или сами идентификаторы сообщений.
5. Для старых подтверждённых строк, у которых нет имени/текста, функция может попытаться получить `username,text` от Meta Graph API по `comment_id`; только после успешной авторизованной проверки идентификатора сохраняет их в Supabase. Если Meta не вернёт доступ к старому комментарию, поля останутся пустыми — ничего не выдумывать.
6. Скрипт Google сопоставляет строки по **ID комментария**, не добавляет дубли, дополняет пустые B/H только фактическими данными. Новые записи — только после подтверждения Meta доставки. Текст комментария экранируется от Google Sheets formula injection.

### Первое подключение владельцем (один раз)

1. Откройте указанную таблицу → **Расширения → Apps Script**. Проект обязательно должен быть привязан к этой таблице, а не создан отдельно.
2. В файле `Code.gs` вставьте полный код [InstagramRecipients.gs](./InstagramRecipients.gs).
3. В настройках Apps Script включите показ `appsscript.json`, затем замените его содержимое [подготовленным manifest](./appsscript.json). Сохраните.
4. Выберите функцию `installInstagramRecipientSync` и нажмите **Выполнить**. Google может попросить подтвердить доступ к текущей таблице, Интернет-запросам и запуску триггера. Подтвердите из аккаунта Google, которому принадлежит таблица.
5. Если выполнение завершилось без ошибки — установка завершена. Триггер появляется в Apps Script → **Триггеры** с частотой 5 минут. Проверить первый запуск через «Выполнения» и таблицу. **Никакого платного сервиса не требуется.**

Временный Google OIDC токен не передавать в чат и не копировать из `Executions`.

### Текущие колонки

A: время отправки (UTC), B: Instagram клиента `@username`, C: ID комментария (как текст), D: «Отправлено», E: создание ссылки (UTC), F: срок ссылки (UTC), G: `@arhittek.plans`, H: «Что написал» (точный текст).

Данные пользователя сохраняются сервером только после `state='sent'`. Неизвестные ранние комментарии или пустые username не подменять именем аккаунта компании.

### Самопроверка

- Прямой `GET /functions/v1/instagram-recipients-export` без Google ID Token возвращает HTTP **401**.
- Валидный Google ID Token от ожидаемого владельца возвращает JSON `rows`, без secrets.
- Статусы `pending`, `failed`, `uncertain` не экспортируются.
- Запуск скрипта два раза не создаёт дубликаты.
- Удаление Google trigger останавливает только синхронизацию таблицы, **не влияет на Instagram Direct**.

### Ограничения

Google может потребовать отдельной авторизации скрипта. Без неё самопроизвольная синхронизация невозможна. Не выдавать подготовленный GitHub-код или развёрнутую Edge Function за уже установленный trigger.
