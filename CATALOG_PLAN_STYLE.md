# Catalogue plan template 3.1

PDF imports use `CatalogPlan` to redraw the source vector geometry before saving
any plan. Internal style version is `arhittek-plan-6`.

- White background, graphite walls, pale blue furniture, neutral windows.
- Soft wall and furniture contact shadows, strictly top-down presentation.
- Source walls, openings, doors, furniture, stair treads and entrance steps.
- Only overall dimensions; source-derived values retain their approximation mark.
- Room names are restored from matched source positions; room areas, page headings, watermarks and material patterns are omitted.
- Room schedules remain in the separate catalogue explication.
- PNG masters are 3600 × 3200; small JPEG thumbnails serve the list.

Geometry is taken from PDF paths rather than freely regenerated by an image model.
Clipping, compound holes, opaque occlusion, hidden layers and paint order are kept.
Thin, winding, dashed and unnumbered stair strokes have pixel regression coverage.
Exterior stair runs can extend the crop without changing structural dimensions.
Shadow masks use half the master resolution to limit memory use on phones.

An ambiguous/scan-only drawing remains blocked rather than silently saving the
original sheet. Missing overall dimensions are reported, never invented. Furniture
is preserved where supplied by the source; absent furniture is not made up.

Matching reimports refresh older style slots and preserve manual fields, facades
and concurrent edits. Existing catalogue images require their matching original
album; a different revision must not replace a stored plan merely because its
project number matches.

Validation: `npm run test:catalog:pdf`, `npm run test:catalog`, `npm run build:check`.

## Legacy image migration

Existing card images without a matching PDF can be restyled from their exact
stored raster using `scripts/catalog-raster-style.py`. This is a reviewed
maintenance path; it must not substitute an archive album with different geometry.
Original image URLs and prior reports are retained in
`pdf_import_meta.plan_style_migration` before the new masters are applied.

The utility removes source annotations, recolours windows neutrally and adds soft
wall shadows. It accepts reviewed dimension corrections, stair protection regions
and annotation masks in original source pixel coordinates. OCR alone is not
sufficient approval for dimension values or wall/stair segmentation: inspect every
output against the stored source before updating a card. Missing floor dimensions
may be represented by an explicit whole-house caption from a confirmed source;
source-derived approximate values retain the approximation mark.

Install Python dependencies from `scripts/requirements-catalog-raster.txt` and
Tesseract with `rus`/`eng` data. Run:

```
python tests/catalog-raster-style.py
python scripts/catalog-raster-style.py source.png output.png --tessdata /path/to/tessdata --dimensions '{"width":12000,"height":16000}'
```

The regression checks wall and window openings, straight and winding stairs,
annotation removal, neutral glazing, shadows, dimensions and thumbnail sizes.
The production upload flow continues to use the PDF vector renderer.

## Basement drawing evidence

A nearby basement schedule is not sufficient to select a drawing. A basement
needs its own level heading or a labelled basement footprint. A partial basement
keeps the complete source drawing; its usable room footprints receive a subtle
highlight. Multiple usable rooms can be highlighted independently.
Coincident solid/pattern fills count as one room. Unrelated sheets are rejected
so the importer can try other candidates.

Dense, short material-hatch strokes spread across a clipped region are removed;
long stair treads are retained. Wall edges use a consistent dark contour. The
synthetic basement regression checks wrong-floor rejection, full-level context and usable-room highlights,
duplicate fills, dimensions, hatch removal and preservation of walls/stairs.

Structural column symbols with source reinforcement hatch are included in the
solid wall cut. Ordinary window and door cutouts remain openings. Floor finishes
are neutral, and only verified usable basement rooms receive a highlight.
